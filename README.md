# Frontend Web Development — In-Class Activities

Repository containing practical in-class projects and coursework for Frontend Web Development.

---

## 📂 Projects

### 1. Canvas Assignment Scraper (`CANVAS_SCRAPER/`)
An automated web scraper built with **Node.js** and **Playwright** that authenticates with the Canvas student portal and inspects assignment pages one by one to extract exact submission statuses, titles, and due dates into structured JSON.
- `scraper.js` — The Playwright scraper script.
- `canvas_assignments.json` — The extracted dataset generated by the scraper.

### 2. SmileSchool Website (`SMILE_WEBSITE/`)
Front-end implementation of the SmileSchool Figma design challenge featuring a hero section, testimonials, courses, and pricing grid.
- `index.html`, `style.css`, `script.js`

### 3. Currency Converter (`CURRENCY_CONVERTER/`)
A responsive currency converter application supporting conversions across multiple currencies with comprehensive validation.
- `index.html`, `style.css`, `app.js`, `currency.js`

### 4. Registration Form (`REGISTRATION_FORM/`)
A responsive student registration form with client-side form validation.
- `index.html`, `new.css`, `script.js`
